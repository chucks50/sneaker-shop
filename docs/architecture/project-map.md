# Sneaker Shop Project Map

## Overview

This project is a sneaker ecommerce storefront built with a React frontend and FastAPI backend, connected to PostgreSQL.

## Frontend

- React + Vite
- React Router
- Shared design tokens and component styles
- Auth context and cart context

## Backend

- FastAPI application
- SQLAlchemy ORM
- JWT-based auth
- Product, cart, checkout and order APIs

## Infrastructure

- Docker Compose for local development
- GitHub Actions for CI
- Vercel or Netlify for frontend hosting
- Render or Railway for backend and database hosting

## Sprint Map

- Sprint 1: setup and environment
- Sprint 2: data model and backend foundation
- Sprint 3: authentication and user management
- Sprint 4: product catalog and storefront shell
- Sprint 5: cart and state management
- Sprint 6: checkout, orders, and mock payment
- Sprint 7: account UX, polish, and deployment
