# Sprint 4 — Product Catalog & Storefront Shell

## Goal

Build the public storefront and product discovery experience.

## Deliverables

- Product listing page
- Product detail page
- Search and filter UI
- Homepage shell
- Product API endpoints

## Scope

- GET /api/products
- GET /api/products/:id
- Homepage featured products
- Product card components
- Category and search filtering

## Acceptance Criteria

- Product list loads from backend
- Product details render correctly
- Filtering and sorting work as expected
- Storefront shell is responsive

## Notes

This sprint establishes the user-facing browsing experience.
