# Sprint 3 — Authentication & User Management

## Goal

Implement user registration, authentication, and protected user routes.

## Deliverables

- Register API
- Login API
- JWT token flow
- Auth guard and middleware
- Profile endpoints

## Scope

- User signup flow
- Password hashing with bcrypt
- Access token and refresh token flow
- Login and logout UX
- Protected account routes

## Acceptance Criteria

- Users can register and log in
- Tokens are validated on protected routes
- Passwords are never stored in plain text
- Login failures return clear errors

## Notes

This sprint unlocks cart, checkout, and account protection.
