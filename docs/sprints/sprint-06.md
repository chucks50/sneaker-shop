# Sprint 6 — Checkout, Orders & Mock Payment

## Goal

Complete the purchase flow from cart to order confirmation.

## Deliverables

- Checkout page
- Order creation API
- Mock payment flow
- Order history API
- Confirmation screen

## Scope

- POST /api/checkout
- Shipping form and order review
- Order record creation
- Payment mock processing
- Order detail and history display

## Acceptance Criteria

- A user can place an order from the cart
- Order records are stored properly
- Confirmation page shows order summary
- Existing orders appear in user order history

## Notes

This is the core commercial flow of the app.
