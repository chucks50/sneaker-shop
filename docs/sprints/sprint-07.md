# Sprint 7 — Account UX, Polish & Deployment

## Goal

Finish the user experience, prepare the app for production, and deploy the project.

## Deliverables

- Account dashboard
- Profile and address management
- UX polish and responsive design
- Production builds
- Deployment pipeline and live deployment

## Scope

- Account pages and profile editing
- Address CRUD flow
- Styling polish and empty/loading states
- CI/CD finalization
- Frontend deployment to Vercel/Netlify
- Backend deployment to Render/Railway

## Acceptance Criteria

- User can manage account settings and view orders
- App is styled consistently across pages
- Frontend and backend build successfully in production mode
- Project is deployed and accessible

## Notes

This sprint is focused on readiness, presentation quality, and deployment.
