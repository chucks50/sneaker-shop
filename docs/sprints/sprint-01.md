# Sprint 1 — Project Setup & Foundation

## Goal

Set up the dev environment, repository structure, and shared developer conventions.

## Deliverables

- Frontend scaffold
- Backend scaffold
- Docker Compose configuration
- CI workflow baseline
- Shared environment variables and project docs

## Scope

- React + Vite frontend app
- FastAPI backend app
- PostgreSQL service in Docker
- Basic GitHub Actions checks
- README and project structure

## Acceptance Criteria

- `docker compose up --build` starts the app stack
- Frontend and backend can communicate locally
- Database is reachable from backend
- CI runs on push and pull request

## Notes

This sprint is foundational. It should be completed before any feature work begins.
