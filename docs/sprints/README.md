# Sprint Documentation

This folder contains the sprint-by-sprint plan for the sneaker webshop project.

## Sprint Overview

1. Sprint 1 — project setup and foundation
2. Sprint 2 — data model and backend foundation
3. Sprint 3 — authentication and user management
4. Sprint 4 — product catalog and storefront shell
5. Sprint 5 — cart and cart state management
6. Sprint 6 — checkout, orders, and mock payment
7. Sprint 7 — account UX, polish, and deployment

## Notes

The sprint plan is designed to align with the architecture document and move from database foundation through shipping-ready MVP features.
