# Sprint 5 — Cart & Local State Management

## Goal

Add cart behavior and client-side state management for the shopping flow.

## Deliverables

- Cart API endpoints
- Cart provider and reducer
- Cart page
- Quantity and remove controls
- Cart totals and persistence

## Scope

- Add to cart actions
- Cart summary updates
- Local state management with React Context
- Removal and quantity updates
- Navbar cart indicator

## Acceptance Criteria

- Products can be added to cart
- Cart totals update correctly
- Items can be updated or removed
- Cart state remains consistent across pages

## Notes

This sprint is the bridge between product browsing and checkout.
